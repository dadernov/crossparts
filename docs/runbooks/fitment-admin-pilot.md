# Пилот применяемости для admin

## Границы

- Аккаунт: только `admin`.
- Группа: только амортизаторы.
- Источники: TRIALLI, TORR, KYB, HOLA и METACO.
- Поиск выполняется только для явно выбранного брендированного артикула.
- Пакет содержит не более 100 уникальных деталей и не обходит кроссы.

## Управление доступом

Проверить право:

```bash
python3 scripts/set_feature_entitlement.py admin vehicle_fitment --enable --max-parts 100
```

Остановить новые запросы без удаления истории:

```bash
python3 scripts/set_feature_entitlement.py admin vehicle_fitment --disable
```

Даже назначенное другому аккаунту право не открывает пилот: серверная
зависимость дополнительно требует точный tenant `admin`.

## Проверка после выпуска

1. Открыть сайт под `admin`: в таблице должна быть колонка «Применимость».
2. Проверить точные карточки KYB `333754`, HOLA `SH20-037G` и METACO
   `4800-013`.
3. Создать пакет, дождаться конечного статуса и скачать XLSX.
4. Вызвать `/api/v1/fitment/metrics` и проверить счётчики кэша/записей.
5. Под любым другим аккаунтом проверить отсутствие элементов интерфейса и
   ответ 403 от fitment API.

## Откат

Сначала отключить entitlement командой выше. Это останавливает новые задачи,
но сохраняет `fitment_jobs`, результаты и evidence. Затем вернуть предыдущий
git commit и перезапустить `crossparts.service`. Новые таблицы можно оставить:
старый код их не использует. Удалять их при оперативном откате не требуется.
