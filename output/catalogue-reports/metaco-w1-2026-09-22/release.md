# METACO W1 — production rollout

Код кандидата прошёл отдельную ветку `catalogue-expansion`, затем по прямому поручению пользователя включён на production 22 сентября 2026 года. Из 21 недостающего адаптера добавлен один источник METACO для двух групп: тормозные колодки и диски. Остальные волны плана не завершены.

Источник — официальные OEM и cross-list CSV со страницы https://metaco.parts/content/downloads. Полный W1 индекс содержит 41 779 связей (34 396 колодок, 7 383 дисков), 2 172 товара. SHA256 снимков и индекса записаны в summary.json. Клиентский поиск не обращается к внешнему сайту.

Источник включён явным правилом source/group/tenant для всех tenant. Подмена source_keys не обходит разрешённые группы. Excel-задача сохраняет tenant; каждая строка с группой ищется только в ней. Поскольку в ручном поиске выбор группы скрыт, отдельный флаг `ungrouped` разрешает METACO проверять обе его группы. Общий HTTP-кэш для METACO отключён, чтобы исключить смешивание групп и устаревших версий индекса.

Финальная проверка перед вторым production restart: 170 offline passed, 10 live skipped, 0 failed. Отдельно live: 9 passed, 1 failed — HEL возвращает ReadTimeout через 45 секунд; повторная проверка дала тот же результат. Это текущая внешняя проблема HEL, а не доказательство отсутствия номера.

40 golden cases (на каждую группу 12 positive + 4 negative + 4 ambiguous) сверены с полным индексом. Исходные пары с доказательствами совпадают точно. После merge все пары бренд/номер/product также сохраняются. Известное ограничение: текущий merge оставляет один kind на номер, хотя OEM и replacement CSV иногда дают разные kind для разных товаров; обнаружено 66 несовпадений метки в доказательствах по проверенным случаям. Это влияет на подпись OEM/аналог, но не удаляет сам кросс-номер.

200 измерений полного локального пути registry → adapter → merge на запрос: 58101H5A25 (425 уникальных пар), p95 47.81 мс; 1K0615301AA (17 пар), p95 0.72 мс. Внешних запросов — 0. Нагрузочный staging baseline, отдельное время очереди и актуальный RSS не измерены.

Перед выпуском сделан согласованный SQLite backup штатным online backup API и сохранён `.env.production`. После запуска `/healthz` и публичный `/api/v1/sources` подтвердили METACO как default для `brake_pads` и `brake_discs`. Прямые runtime-запросы подтвердили `0004200105 → 3000-123` и `1K0615301AA → 3050-016`. Откат выполняется удалением `CP_PILOT_RULES` и перезапуском сервиса; резервная копия находится вне репозитория в `/root/crossparts-deploy-backups/metaco-2026-09-22/`.
